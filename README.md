# Physics in Parallel

Reusable numerical containers, spatial tools, and particle models for Rust.

> **ALPHA / BREAKING RELEASE: 4.1.0-alpha.** This alpha update replaces the 3.x API and
> tightens validation compared with the 4.0 alphas. Review the
> [migration notes](https://github.com/dingyisun0101/Physics-in-Parallel/blob/v4.1.0-alpha/docs/RELEASES.md)
> before upgrading. APIs and data formats may change between alpha releases.
> Pin the exact version. Earlier releases are being retired by yanking them from
> crates.io; existing lockfiles can still use yanked versions.

**[Documentation and getting started](https://github.com/dingyisun0101/Physics-in-Parallel/tree/main/docs)**
· [API reference](https://docs.rs/physics_in_parallel/4.1.0-alpha)

```toml
[dependencies]
physics_in_parallel = "=4.1.0-alpha"
```

Requires Rust 1.97 or newer. Build applications with `cargo build --release`;
see the [release optimization settings](https://github.com/dingyisun0101/Physics-in-Parallel/blob/v4.1.0-alpha/docs/PERFORMANCE.md#release-builds).
